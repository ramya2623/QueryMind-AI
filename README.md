# QueryMind AI

## Overview

QueryMind AI is an AI-powered Business Intelligence platform that enables users to interact with structured data using natural language. Instead of writing complex SQL queries, users can simply ask questions in plain English to retrieve insights from their data.

---

## Problem Statement

Many organizations and individuals store valuable data in databases or CSV files, but extracting meaningful insights often requires SQL knowledge. As a result, they rely on developers or data analysts to answer even simple business questions, leading to delays in decision-making and reduced productivity.

QueryMind AI is an AI-powered business intelligence platform that enables users to interact with their data using natural language. It automatically generates and executes SQL queries, visualizes the results through interactive charts, and provides AI-driven insights to simplify data analysis and support faster, smarter decision-making.

---

## Features

- Upload CSV datasets
- Ask questions in natural language
- AI-generated SQL queries
- Execute SQL on PostgreSQL
- Interactive data visualization
- AI-generated insights
- Query history
